Valrisa Support

Help and contact information for Valrisa applications.

Valrisa Options Tracker

Valrisa Options Tracker is a local-first macOS application for importing brokerage CSV files, organizing options strategies, and reviewing portfolio and income information.

Before contacting support

  • Confirm that you are using the latest version of the app.
  • For import issues, note the brokerage and whether the file contains positions or transactions.
  • For purchase issues, use Restore Purchase while signed in with the Apple Account used for the original purchase.
  • Create a backup before clearing data or performing significant troubleshooting.

Contact support

Email: valrisa-support@slk85.com
Include the product name, app version, macOS or iOS version, device model, and a short description of what happened. Please do not attach brokerage statements, account numbers, passwords, or other sensitive financial information.
